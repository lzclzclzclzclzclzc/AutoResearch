## 已实际完成的运行验证

最终全量回归 **122 passed、0 failed、0 skipped**，耗时 107.24 秒；随后补充的已终止项目控制重启回归 **1 passed**；另有 **2 项前端历史回放检查通过**，TypeScript 检查与 Vite 生产构建通过。5 条 Python 警告来自依赖层的弃用或元数据提示。机器可读结果见 [verification-report.json](docs/verification-report.json)、[JUnit 记录](docs/verification-junit.xml) 与 [补充重启记录](docs/verification-restart-junit.xml)。

- 在本机启动独立 Control、API、Runner 和 Worker。
- 在浏览器创建明确标记的双研究线演示，运行实际 CPU 线性回归进程，记录 17 个逻辑 Agent 的预设发言、验证、Boss 决议、共享记忆和阶段报告。
- 实际启动 Windows 父子进程，验证立即停止、Job 监督进程死亡后的退出和轻量任务的拥有者租约。
- 在业务数据库被持有写锁、写入失败及损坏场景验证独立停止入口；启动器在业务功能失败时仍保留停止和诊断服务。
- 使用官方打包原生 DSH 运行时连接**本机 DeepSeek 消息协议夹具**，以虚拟凭据验证真实 SDK/工具/流式接口。验证未授权 shell 被拒绝、轻量 CPU 工具计算出 6、会话恢复、同一回合幂等，以及人类停止后真实部分消息保留且无后续 Verify。
- 原始非有限指标保存在产物中，传输投影明确标记 NaN/Infinity，严格 JSON 序列化不会把它们替换为 0。
- Verify 交接先落真实消息，再在事务中登记各收件箱、投递回执和唯一 Boss 任务；故障后重试复用原消息。探索、评审及 Boss 后续回合读取持久交接上下文，停止与失效代次不能重新派发。
- 长会话的引用消息可按 ID 独立读取；历史回放仍按当时事件序号还原正文，且拒绝跨研究引用。

## 界面取向

使用 design-taste-frontend 的 Framed sheet 方向，seed `1418577921`。浅色科研工作空间框架、白色内容画布，青色用于组织状态和选中连线；IBM Plex Sans 配合仅用于标识/代码的 IBM Plex Mono。AutoResearch 的分支标记与固定研究线组织图构成产品识别。

列表回答“哪些研究需要关注”；工作台回答“团队正在做什么，依据在哪里”；配置页展示设置产生的真实团队规模。时间补零和研究线编号为实际数据格式；等宽字体只承担标识/代码；阴影只用于浮动的新消息提示，表单焦点环不作为装饰阴影。

静态界面扫描为 0 项失败、6 项提醒：时钟补零、研究线编号、等宽标识、浮动提示阴影、首页区域标签与缺失值横线均按各自用途保留。已在实际浏览器检查 390、768、1440 CSS 像素宽度，以及成员展开、节点选择、手机聊天切换、记忆、报告与只读历史；截图保存在 `docs/screenshots/`。宽度检查使用同源预览框，不等于真实手机硬件性能测试；未执行自动几何/对比度 inspector。
